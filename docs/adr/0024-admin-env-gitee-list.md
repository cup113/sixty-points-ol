# 0024 · 管理员 = 环境变量里的 Gitee id 名单

状态：已接受

## 背景

需要一个人能看全局、能处置僵桌的管理面：谁占着座位、哪张桌停住了、把卡住的人踢出座位、
把废弃的桌删掉。这类需求天然要**碰数据库**。

这个仓库里没有任何角色体系（`users` 表只有 `is_bot`），也不想为「一个运维视图」新建
`roles` / `admins` 表：那会引入一套要同步、要迁移、要防提权的状态，而收益只是一个
部署期就定下来的名单。

更要紧的是**权限挂在哪**：ADR-0023 已经确定 Gitee 身份的令牌永不外发、会话可撤销。
管理员权限正应该挂在这种身份上 —— 挂在本地身份上就等于「一串可复制的字符串 = 管理员」。

## 决策

1. **名单硬编码在部署环境**：`SIXTY_ADMIN_GITEE_IDS`（逗号分隔的 gitee id，单值也行）。
   未设置 = 功能整体不存在；换管理员 = 改部署环境、重启，不动数据库。
2. **判定 = 当前身份绑定的 gitee id 在名单里**。本地身份**永远**不是管理员 —— 这与决策 1
   一起保证「管理员权限不会随可复制的凭据串流出」。
3. **非管理员一律 404**（未登录、本地身份、名单外的 Gitee 身份都一样）：不泄露这个页面存在。
   `load` 与**每个 action** 各自过这道门 —— action 是独立入口，不能只靠 load 挡。
4. **权面就三件写操作**，别的都不做：
   - **强制离座** —— 复用 `leaveSeat`（与在座者自己点「离座」同一条路：座位空出等补位、
     本人转观战者，含广播）；
   - **级联删牌桌** —— `tables/seats/games/events/replays/spectators` 五张从表一起删；
   - **删用户（级联删座）** —— 见决策 5。
   不提供 SQL 控制台：那等于把整个库押在一个会话的安全上，而 SQLite 能写能删表。
5. **删用户的级联语义**（每一处都是外键或领域事实强制的）：
   - 他在每张桌的**座位行删除** = 强制离座语义（进行中的那一副停在空座等补位），逐桌广播；
     **不写观战记录** —— 人都要删了，观战意愿没有意义（机器人的 `removeBot` 同理）；
   - 他**主持**的桌（`host_user_id`）：**还有人坐** → 改成最小编号的在座者；
     **一座不剩** → 整桌级联删。`host_user_id` 是装饰字段（全库无消费者），
     但它是 `NOT NULL` 外键，所以必须有个归宿；一座不剩的桌再也无法开局，留着是死数据；
   - `sessions`（Gitee 登录态）、`spectators`、机器人定时器一并清；名字回池可复用；
   - **不能删管理员自己当前登录的身份**：会话随删即失效，误触代价太大。
6. **写操作只走 POST**（SameSite=Lax 的会话 cookie 已经拒掉跨站表单提交）。

## 后果

- 管理员必须**走 Gitee 登录**：本地身份进不去管理面，而 Gitee 身份没有可复制的凭据串。
  这是与 ADR-0023 配套的一半 —— 两条合起来才成立「管理权限不外流」。
- 删用户会连带删掉「一座不剩且由他主持」的**空桌**（连同牌局、事件、重演）。这是有意的：
  那种桌已经无法开局，而外键又要求 host 有归宿。桌里还有别人在座时，桌会活下来并换 host。
- 被删用户**已连着的 SSE 不会主动掐断**：连接在下一帧发现自己不在任何座位上（观战负载），
  下一次请求则因会话/凭据消失而 401 —— 与「离座后关页面」的既有口径一致。
- 名单不含自己时页面**对管理员也 404**，症状是「明明配了却打不开」：这是决策 3 的代价，
  排查时先看环境变量里那个 gitee id 与 `users.gitee_id` 是否逐字相同（数字 id 的字符串形式）。
- 页面按桌面端验收（手机端不管）；时间戳按本地钟写成 `MM-DD HH:mm`。

## 守卫

- **判定**（`test/auth-gitee.test.ts`）：逗号名单忽略空白；名单内的 Gitee 身份是、
  名单外/本地身份/未登录/未配置都不是。
- **级联**（同一文件）：删用户后座位/会话/观战记录/用户行为 0、名字可再注册；
  主持的桌有人时换 host 且桌还在、一座不剩时整桌五张表清空并报出邀请码；
  删桌后五张从表为 0 且重复删返回 false；不能自删；强制离座后本人留下观战记录。
- **版面**（`pnpm shot:gitee`）：管理面板那两屏断言「强制离座 / 删桌 / 删用户」三个入口都在。
