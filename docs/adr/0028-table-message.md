# 桌边消息：一个座位一条气泡，暂离也只是消息

牌桌上一直缺一件很小的事：说一句「等我一下」、发一颗表情，或者告诉另外两家「我暂离十分钟」。
README 的「暂未实现」里把它写作「聊天/表情」。这一条把它收成一个**不做聊天**的形状：
没有消息记录、没有未读、没有第二个页签，每个座位同一时刻只有**一条**气泡。

## 决策

1. **一个座位一条消息**（`announcements` 表，`UNIQUE (table_id, user_id)`）。
   三种消息共用同一个表面：`emote`（8 个固定表情之一）、`text`（最多 24 字的一句短话）、
   `away`（带一个到点时刻的暂离）。新消息覆盖旧消息 —— 每个人的状态就是「最近一条的动作」。
2. **暂离不是一种座位状态，而是一条消息**。第一版草图把它做成座位卡上替换等级徽标的
   `暂离 8 分` 徽章，那会在卡片里再开一个槽位、把名字列再挤一次。这里改成与表情、短句
   共用同一个气泡：`暂离` + `还剩 14 分`。到点气泡自己消失，不需要服务端定时器；
   **牌局动作**（叫牌/埋底/出牌/发牌/开新对局）会提前删掉**暂离**那条 ——
   短句与表情照旧活到自己的 TTL，别让下一次出手把刚说的话吞掉。
3. **气泡是 `absolute` 的按钮**：它不占座位卡的高度，也不参与毡面的行高。点一下只在
   **本地**收起（`dismissedId = announcement.id`），不发请求、不广播 ——
   谁点掉的只对谁生效，别人不该被你替他们关掉消息。它会遮住一点牌面，这是接受的代价，
   收起它的动作就在它自己身上。
4. **寿命由服务端算成剩余毫秒**（`SeatAnnouncement.remainingMs`），浏览器只做本地倒数。
   表情 6 秒、短句 10 秒、暂离就是所选的那一档（5/10/15/30/45/60 分钟）。到 0 就隐藏；
   下一次读负载时服务端已经不再返回它。**时间不进引擎**，也不传时间戳（与「距上一步」
   计时同一条纪律：跨端不对钟）。
5. **入口只有一个**：「我」底栏右端那枚笑脸（`SocialControl`）。弹层里是 8 个表情、
   一个单行输入框与一枚「暂离」按钮；点「暂离」才展开六档时长。
   入口不在页头（白名单已满）、不在操作条（那一行住牌局动作）、也不进抽屉（抽屉是查阅面）。
   观战者没有底栏，所以**没有入口**是结构性的，不靠禁用按钮。
6. **观战者只看不发**。消息挂在座位卡上，观战者没有座位卡可挂；要让他们发言就得再开一个
   展示面，那已经不是「简易」的量。
7. **服务端三条边界**：在座才能发（403）、同一个人 2 秒一条（429）、表情键 / 档位 / 长度
   都在服务端再验一次。座位由身份推导，不接受客户端传。
8. **没有历史、没有未读、没有抽屉页**。刷新/重连不会补发已经消失的消息；换设备看不到
   之前说过什么。这不是暂未实现，而是这个功能的边界：它不是聊天。
9. **不进 MCP 工具面**。它不改变牌局，也不是「此刻行动所需」的信息；`wire.ts` 只为
   `SeatInfo.announcement` 跟着长一个字段（形状守卫会核对），工具面不新增工具。
10. **写路径不重试**：与动作接口同一条纪律 —— 服务端没有幂等键，重发就是「再说一条」。

## 取舍与后果

- **不做聊天面板**：抽屉第五页、消息表、输入框、未读角标、长度/频率/脏话/保留期、
  手机端整屏盖住牌桌 —— 这些都是「聊天」的成本。牌桌的纪律是「可见文字是成本」，
  而一句「等我一下」不需要一套消息系统。
- **不做常驻暂离状态**：常驻状态要占一个槽位、要服务端定时器把到点的徽标收掉、
  还要回答「暂离的人算不算在线」。做成消息之后这些都不存在：它只是一条会过期的气泡，
  到点就没了。
- **气泡会遮住牌**：24 字在 176px 宽里折 2–3 行，会盖住说话人的名字/等级或旁边一点牌面。
  点击收起是唯一的解法；不为了不遮挡而把消息塞进第二个展示面（那会把「一条气泡」
  变成「一块聊天区」）。
- **同一身份多标签页**：最后一次写入赢；没有按连接区分，也没有已读回执。
- **限速是 2 秒一条**：足够说一句、回一颗表情；不够刷屏。被拒时面板底部给出原因，
  不把人赶去页头找红字。
- **暂离到点时没有广播**：其他浏览器靠本地倒数隐藏；服务端在下一次读负载时不再返回它。
  代价是「所有人同时看到它消失」不保证（各自钟差几十毫秒），换来的是零定时器、零后台任务。

## 守卫

- `apps/web/test/social.test.ts`：纯函数（目录/长度/档位/剩余文案/解析）+ 真 SQLite
  （在座才能发、2 秒限速、观战 403、到点不返回、牌局动作只清暂离、离座带走消息）。
- `apps/web/test/table-chrome.test.ts` 的 `socialSourceCheck`：入口只在「我」底栏、
  气泡必须是本地可收起的绝对定位按钮、目录只有 `social.ts` 一份、服务端有限速与表情校验、
  `announcements` 是「一桌一座位一条」；含五条反证（入口挪页头、气泡回流内、气泡写服务端、
  控制条写死表情、去掉限速）。
- `apps/web/scripts/ui-check.ts`：出货 HTML 上验短句真的渲染成气泡、尖括号被转义、
  暂离气泡带「还剩 N 分」、入口带可读名字、首帧没有输入框。
- `packages/mcp/scripts/mcp-check.ts` 的形状守卫：`SeatInfo.announcement` 必须与
  `wire.ts` 的声明逐字段一致。
