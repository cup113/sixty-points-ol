## 约定

- **教练栏**＝你（学习者）这个动作的引导词，学习者每个动作必有一条（与正式校验同一铁律，生成时已断言）。
- **解说**＝对手动作的一句旁白，可选；没写的就静默自动出牌。
- `⟨…⟩`＝交互占位（点哪张牌 / 哪个叫品 / 哪个按钮），接线时由现有 UI 承接。
- 每墩开头的三家手牌为**评审全亮**；玩家实际只见自己那一行（个人视角），复盘屏才全亮。
- 所有数字（墩分、结算、级别、升级档位、手牌快照）由脚本从**引擎重放**注入，不是手写；叙述与表冲突时以表为准，报我即改。
